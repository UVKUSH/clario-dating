## A note on assets

Local media used while working on this project lives in an `assests/` folder on
disk that is **intentionally not tracked in git**. Both `assests/` and `assets/`
are ignored, so renaming the folder to the correct spelling will not accidentally
start publishing its contents. If you clone this repo, that folder will be absent —
that is expected.
